在 OpenAnolis 上安装 FreeSWITCH

✅ 一、环境准备（OpenAnolis 3）

  1. 确认系统版本
cat /etc/os-release

确认类似输出：

ID="alinux"
ID_LIKE="rhel fedora centos anolis"
  1. 更新系统依赖
sudo dnf update -y

🧰 二、安装编译依赖

FreeSWITCH 从源码编译较稳定，安装依赖如下：

sudo dnf groupinstall "Development Tools" -y

sudo dnf install -y \
  autoconf automake libtool gcc gcc-c++ make ncurses-devel \
  libuuid-devel libxml2-devel sqlite-devel \
  libedit-devel openssl-devel \
  curl-devel libcurl-devel \
  git-core zlib-devel \
  pcre-devel speex-devel \
  ldns-devel libsndfile-devel \
  libjpeg-devel spandsp-devel \
  opus opus-devel \
  lua lua-devel \
  speexdsp speexdsp-devel \
  which nasm

📥 三、下载 FreeSWITCH 源码

cd /usr/src
git clone https://github.com/signalwire/freeswitch.git
cd freeswitch

🔧 四、配置编译选项

  1. 拉取模块依赖：
./bootstrap.sh -j
  1. 配置（默认启用常用模块）：
./configure --without-pgsql --prefix=/usr/local/freeswitch 

# 参考centos 安装 取消不需要的模块
# --enable-core-pgsql-support 可以添加这个对 PgSql的支持

你也可以添加 --prefix=/usr/local/freeswitch 指定安装路径。

问题解决:

# checking for libmariadb >= 3.0.9... checking for mariadb >= 3.0.9... no
sudo dnf install -y mariadb-connector-c-devel

# checking for PQgetvalue in -lpq... no 
sudo dnf install -y postgresql-devel

# 其他问题参考centos安装

🏗️ 五、编译与安装

安装spandsp 和 sofia-sip模块

# (自v1.10.4版本后,这两个模块需要单独编译,因为源码依赖了,所以需要提前安装)
# 如果git拉不下来,则直接下载zip再单独上传
cd /usr/src/freeswitch
# 目前最新的spandsp和fs最新代码不兼容,所以指定版本拉取
git clone https://github.com/freeswitch/spandsp.git
# spandsp目录下执行git log或者gitlab上查看对应commit id并切换
git checkout -b finecode20230705 0d2e6ac65e0e8f53d652665a743015a88bf048d4
# 编译spandsp
cd /usr/local/src/freeswitch/spandsp
./bootstrap.sh
./configure
make -j
make install

# 添加库的路径到系统
export PKG_CONFIG_PATH=/usr/local/lib/pkgconfig:${PKG_CONFIG_PATH} 
ldconfig

# 安装 sofia-sip 依赖 
# (自v1.10.4版本后,这两个模块需要单独编译,因为源码依赖了,所以需要提前安装)
git clone https://github.com/freeswitch/sofia-sip.git
# 编译sofia-sip
cd /usr/src/freeswitch/sofia-sip
./bootstrap.sh
./configure
make -j$(nproc)
make install

编译并安装

make -j$(nproc)
sudo make install
# 安装声音模块
sudo make sounds-install moh-install

设置软连接

# 配置命令软连接 freeswitch默认安装路径/usr/local/freeswitch
ln -sf /usr/local/freeswitch/bin/freeswitch /usr/local/bin/
ln -sf /usr/local/freeswitch/bin/fs_cli /usr/local/bin/

🖥️ 六、设置 systemd 启动脚本

创建 systemd 文件：

sudo nano /etc/systemd/system/freeswitch.service

填入如下内容（修改路径为实际安装目录）：

[Unit]
Description=FreeSWITCH
After=network.target

[Service]
User=root
Group=root
Type=forking
ExecStart=/usr/local/freeswitch/bin/freeswitch -nc
ExecStop=/usr/local/freeswitch/bin/freeswitch -stop
PIDFile=/usr/local/freeswitch/var/run/freeswitch/freeswitch.pid
LimitCORE=infinity
LimitNOFILE=100000
LimitNPROC=60000
Restart=always

[Install]
WantedBy=multi-user.target

启动并设置开机自启：

sudo systemctl daemon-reexec
sudo systemctl daemon-reload
sudo systemctl enable freeswitch

✅ 七、验证是否运行成功

sudo systemctl status freeswitch

查看端口监听情况：

netstat -tunlp | grep 5060

或使用：

/usr/local/freeswitch/bin/fs_cli

进入 FreeSWITCH 控制台。

🧱 常见问题

问题原因解决方案
cannot find opensslOpenSSL 安装不完全安装 openssl-devel
编译失败在 spandsp依赖缺失或冲突升级或重新安装 spandsp-devel
启动失败端口冲突5060 被占用修改配置 /usr/local/freeswitch/conf/sip_profiles/internal.xml

🚀 总结

  • OpenAnolis 基于 RHEL，所以 FreeSWITCH 安装流程与 CentOS 几乎一致。
  • 建议使用源码编译方式，便于后续扩展模块与调试。
  • 安装完毕后，可通过 fs_cli 进行控制和管理。
