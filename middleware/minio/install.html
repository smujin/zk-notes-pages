参考地址

https://www.minio.org.cn/docs/minio/linux/operations/install-deploy-manage/deploy-minio-single-node-single-drive.html

1. 安装Minio(amd64格式)

# 先查看CPU的架构,选择正确的安装包
uname -m
输出架构类型说明
x86_64amd64常见于 Intel/AMD PC
aarch64arm64常见于 Apple M 系列、ARM 服务器
armv7l32 位 ARM比如树莓派等
i686x86 (32位)比较老的架构
# 下载最新的minio 包,并直接安装
wget https://dl.min.io/server/minio/release/linux-amd64/archive/minio-20250312180418.0.0-1.x86_64.rpm -O minio.rpm
sudo dnf install minio.rpm

2. 单节点单硬盘部署

# 1. 创建环境变量文件
vim /etc/default/minio
# 添加以下内容
# MINIO_ROOT_USER and MINIO_ROOT_PASSWORD sets the root account for the MinIO server.
# This user has unrestricted permissions to perform S3 and administrative API operations on any resource in the deployment.
# Omit to use the default values 'minioadmin:minioadmin'.
# MinIO recommends setting non-default values as a best practice, regardless of environment

# 修改成自己的账号密码
MINIO_ROOT_USER=myminioadmin
MINIO_ROOT_PASSWORD=minio-secret-key-change-me

# MINIO_VOLUMES sets the storage volume or path to use for the MinIO server.
# 文件存储路径
MINIO_VOLUMES="/mnt/data"

# MINIO_OPTS sets any additional commandline options to pass to the MinIO server.
# For example, `--console-other :9001` sets the MinIO Console listen port
# 控制台打开端口
MINIO_OPTS="--console-address :9001"

如果想以root用户启动,需要修改启动文件

vim /usr/lib/systemd/system/minio.service
User=root
Group=root
# 使修改生效
systemctl daemon-reload

# 启动Minio
sudo systemctl start minio.service

# 重新启动后自启
sudo systemctl enable minio.service
