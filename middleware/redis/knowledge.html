1. 什么是Redis

Redis是一个开源（BSD许可），内存存储的数据结构服务器，可用作数据库，高速缓存和消息队列代理。它支持 字符串、 哈希表、 列表、 集合、 有序集合、 位图、 hyperloglogs 等数据类型。内置复制、Lua脚本、LRU收回、事务以及不同级别磁盘持久化功能，同时通过Redis Sentinel提供高可用，通过Redis Cluster提供自动分区

Redis 数据类型与 Java 场景映射表（含操作接口）

Java 使用场景 / 方法推荐 Redis 数据类型使用建议 / 说明Java 操作接口示例
缓存简单的对象（如 token、配置值）String适合缓存单个键值对；可设置过期时间StringRedisTemplate / ValueOperations
用户登录状态（token -> userId）String用作 Session 存储或登录状态缓存；设置过期时间StringRedisTemplate / ValueOperations
用户对象、商品详情等结构化数据缓存Hash将对象字段拆分为 Hash 的 field；方便更新单个属性HashOperations<String, String, Object>
用户浏览记录、消息队列（先进先出）List使用 LPUSH + RPOP 实现队列功能ListOperations<String, String>
发布/订阅消息推送PubSub / List实时推送消息可用 Redis Pub/Sub，非实时可用 List + 消费者RedisMessageListenerContainer / ListOperations
标签、兴趣等无序唯一集合Set适合记录用户兴趣、标签等；可做集合运算SetOperations<String, String>
共同好友、交集运算等集合运算SetRedis 支持交/并/差集操作，适用于社交功能SetOperations
排行榜（按分数排序，如游戏分数）Sorted Set (ZSet)score 表示排名值，可按分数排序ZSetOperations<String, String>
记录访问次数、点赞次数等频繁递增操作String (Counter)使用 INCR、INCRBY 实现高效计数器ValueOperations.increment(key)
签到、在线状态等位操作Bitmap使用位图记录某日是否签到、某人是否在线；节省空间RedisConnection.setBit()
全站 UV（去重用户数统计）HyperLogLog支持大规模基数估算，误差约 0.81%；不支持删除元素RedisTemplate.execute(HyperLogLogCommands) 或 Lua
用户推荐、匹配等带排序的推荐功能Sorted Set (ZSet)根据匹配度打分排序，可动态调整分数ZSetOperations
限流（IP、接口请求频率限制）String + Lua结合计数器与过期时间，或用 Lua 脚本实现精准限流RedisTemplate + Lua 脚本执行
延迟队列 / 任务调度Sorted Set + 时间戳利用 score 存时间戳，轮询取出已到期任务ZSetOperations
购物车、临时订单存储（多个字段）Hash一个用户一条 Hash 记录；结构清晰，易维护HashOperations
用户行为日志（可有序保存最近 N 条）List使用 LPUSH + LTRIM 保持定长列表ListOperations
