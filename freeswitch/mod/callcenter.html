callCenter模块

Mr.zhu2026年8月24日小于 1 分钟

群呼任务修改

  1. fs 要安装 mod_mariadb 配置 autoload_configs/pre_load_modules.conf.xml 打开该模块 配置 switch.xml 链接数据库
  2. fs 要安装 mod_xml_url 模块 配置 autoload_configs/modules.conf.xml 打开该模块 并配置 autoload_configs/xml_url.conf.xml
  3. fs 要安装 mod_callcenter 模块 配置 autoload_configs/modules.conf.xml 打开该模块 并配置 callcenter.conf.xml 链接数据库

fs_cli -H 127.0.0.1 -P 8021 -p ClueCon

查看所有队列·-

callcenter_config queue list

添加一个队列

callcenter_config queue add task_2443

往指定队列里面添加一个坐席

callcenter_config tier add task_1681 1_15680962149

callcenter_config tier del task_1681 1001

callcenter_config agent set status 1001 Available callcenter_config agent set status 1001 On Break

假设这个座席的分机号是 1001

callcenter_config agent add 1001 callback

callcenter_config agent set contact 1001 user/1001

callcenter_config agent list 1547_1275574

发起呼叫

originate {group_task_id=1681,group_mobile_id=1,playback_loops=1,ignore_early_media=true,origination_timeout=30}user/1002 'playback:usr/local/freeswitch/prerecordings/20260325162406_DA39A16C8FCD6779.wav,callcenter:task_1681' inline

查看客户等待情况

callcenter_config queue list members task_1861

查看某个队列的所有坐席情况

callcenter_config queue list agents task_2000
