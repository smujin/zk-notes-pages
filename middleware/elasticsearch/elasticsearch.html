Elasticsearch 学习

一： Elasticsearch 安装

https://mirrors.huaweicloud.com/elasticsearch/7.6.1/?C=N&O=D 可以点击此链接下载，华为云比官网快很多

windows 解压配置点击bin目录的 elasticsearch.bat 即可启动

默认访问页面的端口是 9100

访问地址: http://localhost:9200/

1.1 elasticsearch-head 插件

https://github.com/mobz/elasticsearch-head 在此网址即可下载并安装使用

#插件默认端口是 9300 ES默认端口是 9200
# 安装依赖
npm install
# 启动插件
npm run start

1.2 head 插件显示东西会跨域

所以需要设置ES跨域 在conf目录下elasticsearch.yml 文件添加

# 添加如下代码即可设置ES跨域
http.cors.enabled: true
http.cors.allow-origin: "*"

插件访问地址是 http://localhost:9100/

四: 插件: ik分词器

4.1: 下载ik分词器

如果要使用中文,就要使用中文分词器

什么是IK分词器？

分词： 即把一段中文或别的划分成一个个的关键字，我们在搜索的时候会把自己的信息进行分词，会把数据库中或者索引库中的数据进行分词，然后进行一个匹配操作，默认的中文分词是将每个字看成一个词。这显然是不符合要求的，所以我们需要安装中文分词器来解决这个问题.

如果要使用中文，建议使用IK分词器！

ik分词器提供了两个分词算法: ik_smart和ik_max_word，其中ik_smart为最少切分，ik_max_word为最细粒度划分!

https://github.com/medcl/elasticsearch-analysis-ik

下载后解压到elasticsearch安装路径下plugins文件夹下

4.2 重启ES观察

下载版本，需要将其打包，查看教程： https://www.cnblogs.com/dyha/p/14141604.html

可以通过elasticsearch-plugin list 查看已经安装的插件

4.3 分词算法

​ 1、ik_smart 最少切分，ik_max_word 最细粒度切分

# kibana
GET _analyze
{
	"analyzer": "ik_smart",
	"text": "今天天气真好"
}

GET _analyze
{
	"analyzer": "ik_max_word",
	"text": "今天天气真好"
}
4.4 ik分词器增加自己的配置

当我们需要一些特别的词，而分词器以最小拆分的话，没有我们需要的词，这时候可以自己去配置分词器

可以在 elasticsearch-7.6.1\plugins\analysis-ik\config 目录下创建 zhu.dic 词典文件（需要改成utf-8格式）,然后在同目录下

IKAnalyzer.cfg.xml 文件中引用即可

需要重启ES

六: 文档操作

6.1、 基本操作

6.1.1、 添加数据

PUT /kuangshen/user/1
{
  "name": "狂神说",
  "age": 23,
  "desc": "一顿操作猛如虎,一看战绩0-5",
  "tags": ["技术宅","温暖","直男"]
}
6.2 、简单搜索
//获取文档内容
GET /kuangshen/user/1
// get q 是query 后面是查询条件    
GET /kuangshen/user/_search?q=name:狂神说java
6.3 、复杂操作搜索 select （排序,分页,高亮,模糊查询）

​ 得到结果值中 _score 值越高就显得越匹配

//查询,包含精准查询,指定字段,排序,分页
GET /kuangshen/user/_search
// 查询的参数体
{
  "query": {
    //精准查询,这个是去分词器进行查询
    "match": {
      "name": "狂神"
    }
  },
  //指定只查询出来的字段
  "_source": ["name","desc"],
  //排序
  "sort": [
    {
      //通过那个字段进行排序
      "age": {
        //排序的规则 desc倒序,asc 正序
        "order": "desc"
      }
    }
  ],
  //从第几个数据开始
  "from": 0,
  //返回多少条数据
  "size": 10
}

//2. 布尔值查询
//must (相当于mysql里面的and,都要匹配)  should(相当于mysql里面的or) must_not(相当于查询不匹配的)
//gt大于, lt小于,gte大于等于,lte小于等于
GET /kuangshen/user/_search
{
  "query": {
    "bool": {
      //一定匹配,此处可以替换上面的命令
      "must": [
        {
         //分词器查询
         "match": {
           "name": "狂神说"
         }
        },
        {
          "match": {
            "age": "23"
          }
        }
      ],
      //过滤操作
      "filter": {
        //范围
        "range": {
          "age": {
            //gt 大于  
            "gt": 10,
            //lt 小于  
            "lt": 20
          }
        }
      }
    }
  }
}

// 匹配多个条件查询
GET /kuangshen/user/_search
{
  "query": {
    "match": {
      //多个条件使用空格隔开,只要满足其中一个即可，可以稍微理解为 in 
      "tags": "男 技术"
    }
  }
}

//精确查询
term 是通过倒排索引指定词条进行精确查询的
term,直接查询精确的
match,会使用分词器解析!(先分析文档,然后在通过分析文档进行查询)
//两个类型
text 会被分词器进行解析
keyword 不会被分词器进行解析

//按照 keyword方式进行分词
GET _analyze
{
  "analyzer": "keyword"
  , "text": "狂神说Java name"
}
// 按照标准进行分词
GET _analyze
{
  "analyzer": "standard"
  , "text": "狂神说Java name"
}

// 高亮查询
GET /kuangshen/user/_search
{
  "query": {
    "match": {
      "name": "狂神"
    }
  },
  //高亮
  "highlight": {
    //自定义高亮标签
    "pre_tags": "<p class='key'>",
    //自定义高亮结束标签
    "post_tags": "</p>",
    //匹配高亮字段
    "fields": {
      //需要显示高亮的字段名
      "name":{}
    }
  }
}
