Linux(centos系统) 源码安装FreeSWITCH 安装版本1.10.12

版本兼容问题

  1. FreeSWITCH 1.10.12 只能使用特定的 spandsp 版本
  2. 注意查看数据库兼容问题
  3. 注意禁用不需要的模块

参考地址

https://blog.csdn.net/qq_36369267/article/details/131564019

1. 安装基础依赖

# 1. 更新 yum 源
yum update
# 2. 安装基础依赖
yum install -y git alsa-lib-devel autoconf automake bison broadvoice-devel bzip2 curl-devel libdb4-devel e2fsprogs-devel erlang flite-devel g722_1-devel gcc-c++ gdbm-devel gnutls-devel ilbc2-devel ldns-devel libcodec2-devel libcurl-devel libedit-devel libidn-devel libjpeg-devel libmemcached-devel libogg-devel libsilk-devel libsndfile-devel libtheora-devel libtiff-devel libtool libuuid-devel libvorbis-devel libxml2-devel lua-devel lzo-devel mongo-c-driver-devel ncurses-devel net-snmp-devel openssl-devel opus-devel pcre-devel perl perl-ExtUtils-Embed pkgconfig portaudio-devel postgresql-devel python-devel python-devel soundtouch-devel speex-devel sqlite-devel unbound-devel unixODBC-devel wget which yasm zlib-devel libshout-devel libmpg123-devel lame-devel

2. 下载源码

cd /usr/src
git clone -b v1.10.12 https://github.com/signalwire/freeswitch

3. 禁用不需要的模块

# 禁用不需要的模块,否则make时会报错, 同时也可以打开需要的模块,例如 mod_MariaDB
cd /usr/src/freeswitch
vim module.conf
#applications/mod_signalwire (禁用mod_signalwire)
#applications/mod_av (禁用mod_av)

# mod_verto不禁用可能会编译报错You need to either install libks or disable mod_verto in modules.conf
#endpoints/mod_verto  (禁用mod_verto)

4. 编译安装源码

cd /usr/src/freeswitch
# 执行
./bootstrap.sh
# 校验依赖
./configure --without-pgsql --prefix=/usr/local/freeswitch 
# 如果出错则查看第五步处理完再继续执行命令
make -j$(nproc)
make install

5. 安装spandsp 和 sofia-sip模块

# (自v1.10.4版本后,这两个模块需要单独编译,因为源码依赖了,所以需要提前安装)
# 如果git拉不下来,则直接下载zip再单独上传
cd /usr/src/freeswitch
# 目前最新的spandsp和fs最新代码不兼容,所以指定版本拉取
git clone https://github.com/freeswitch/spandsp.git
# 编译spandsp
cd /usr/src/freeswitch/spandsp
# spandsp目录下执行git log或者gitlab上查看对应commit id并切换
git checkout -b finecode20230705 0d2e6ac65e0e8f53d652665a743015a88bf048d4
./bootstrap.sh
./configure
make -j$(nproc)
make install

# 添加库的路径到系统
export PKG_CONFIG_PATH=/usr/local/lib/pkgconfig:${PKG_CONFIG_PATH} 
ldconfig

# 安装 sofia-sip 依赖 
# (自v1.10.4版本后,这两个模块需要单独编译,因为源码依赖了,所以需要提前安装)
git clone https://github.com/freeswitch/sofia-sip.git
# 编译sofia-sip
cd /usr/freeswitch/sofia-sip
./bootstrap.sh
./configure
make -j$(nproc)
make install

6. 设置软连接

# 配置命令软连接 freeswitch默认安装路径/usr/local/freeswitch
ln -sf /usr/local/freeswitch/bin/freeswitch /usr/local/bin/
ln -sf /usr/local/freeswitch/bin/fs_cli /usr/local/bin/
